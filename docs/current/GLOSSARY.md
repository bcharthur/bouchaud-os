# Glossaire

BrowserHost — UI/orchestration navigateur.  
WebContent — processus document/rendu.  
WebWorker — worker web dédié.  
RequestServer — réseau/cache.  
Compositor — trames navigateur.  
OOPIF — frame isolée dans un autre processus.  
Process swap — changement de WebContent pour autre site.  
Backing store — mémoire de surface.  
TCG — émulation QEMU.  
KVM — virtualisation matérielle.  
PHYSICAL — preuve sur TRIGKEY.  
NNP — no_new_privs.  
WPT — Web Platform Tests.  
BRDP — contrôle distant Bouchaud.
