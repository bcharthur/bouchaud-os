# Observabilité et fiabilité

Bouchaud OS utilise :
- journal série ;
- blackbox ;
- télémétrie ;
- BRDP ;
- profiler RIP ;
- stats processus/syscalls ;
- RSS et objets Compositor ;
- compteurs disque ;
- métriques scheduler.

Principe : attribuer un symptôme avant de modifier un budget ou une architecture.
