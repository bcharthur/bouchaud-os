## 2. Avancées de la session

### 2.1 Client graphique générique (DOOM sans écran Ladybird) — HOST (compilation)

- `Client::lance(chemin, titre, …)` : le titre est celui de l'application lancée (`BOUCHAUD_GUI_CLIENT_GENERIQUE_V1`).
- L'écran d'attente est le même pour toute application ring 3 : nom de l'application et chronomètre ; le texte propre au navigateur est retiré.
- `BO_AUTOSTART_DOOM=1` (bancs QEMU sans souris) ouvre DOOM par le même chemin que l'icône.
- `tools/doom/build-linux.sh` : DOOM (Doomgeneric épinglé, Freedoom 0.13.0 vérifié) construit sous Linux avec musl, même contrat ELF que `build-windows.ps1`.

### 2.2 P10 — intégration de #281 et premier essai local — TCG

Essai local QEMU 8.2 TCG, `-vga none -device virtio-gpu-gl-pci -display sdl,gl=on` sous Xvfb (virglrenderer sur llvmpipe côté hôte), noyau `p10-universal-present,p10-virgl-experimental`, DOOM lancé par `BO_AUTOSTART_DOOM=1` :

- `P10_GPU_3D_OK capset=2 version=2` : contexte VIRGL réel ;
- DOOM tourne (≈ 85–95 FPS bureau), `P10_GPU_QUEUE … echecs=0 saturation=0`, ≈ 7,9 ms par présentation ;
- **mais** `P10_GPU_CLIENT_BLIT_OK` n'apparaît jamais : le pointeur au centre de l'écran est au-dessus de la fenêtre DOOM, ce qui désactive le chemin GPU ; chaque trame recopie deux fois l'écran entier par le processeur (instantané + mémoire du scanout). Ce n'est pas encore une accélération.

### 2.3 P10 — compositeur GPU V2 (remplace le chemin #281) — TCG local

Détail complet : [P10_GPU_COMPOSITEUR.md](P10_GPU_COMPOSITEUR.md).

- Textures VIRGL adossées aux **pages mêmes** des surfaces clientes ; transfert du seul rectangle abîmé par l'hôte ; un `SUBMIT_3D` de BLIT par trame ; un flush. Le CPU invité ne recopie plus de pixels clients.
- Découpe exacte sous les calques supérieurs (ombres, dock, menus, curseur) : le CPU peint ces pixels-là, le GPU le reste.
- Cause du retournement de #281 trouvée et mesurée (BLIT en coordonnées GL brutes) ; **autotest de convention au démarrage** (BLIT relu au pixel).
- Toujours compilé ; actif seulement si VIRGL est proposé et que l'autotest passe. Code « présent universel » de #281 (deux copies plein écran par trame) retiré.
- Banc `tools/ci/run_gpu_composition.sh` (TCG local) : mire **254 934 pixels exacts, 0 faux** ; A/B DOOM **CONVAINCANT** (dessin CPU ÷15,7, pixels clients CPU −99,9 %, cadence conservée) ; repli 2D OK.
- Gardes : 210/210 ; suites hôte Rust 141/141 ; pile noyau sous budget.

### 2.4 Fenêtres cachées — TCG local

Endurance locale DOOM + mire superposées : DOOM, caché, faisait encore recopier ≈ 500 M pixels / 30 s au CPU (les coins arrondis empêchaient l'élagage du plan de scène).
