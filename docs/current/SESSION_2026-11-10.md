- `P10_GPU_3D_OK capset=2 version=2` : contexte VIRGL réel ;
- DOOM tourne (≈ 85–95 FPS bureau), `P10_GPU_QUEUE … echecs=0 saturation=0`, ≈ 7,9 ms par présentation ;

### 2.3 P10 — compositeur GPU V2 (remplace le chemin #281) — TCG local

Détail complet : [P10_GPU_COMPOSITEUR.md](P10_GPU_COMPOSITEUR.md).

- Textures VIRGL adossées aux **pages mêmes** des surfaces clientes ; transfert du seul rectangle abîmé par l'hôte ; un `SUBMIT_3D` de BLIT par trame ; un flush. Le CPU invité ne recopie plus de pixels clients.
- Découpe exacte sous les calques supérieurs (ombres, dock, menus, curseur) : le CPU peint ces pixels-là, le GPU le reste.
- Cause du retournement de #281 trouvée et mesurée (BLIT en coordonnées GL brutes) ; **autotest de convention au démarrage** (BLIT relu au pixel).
- Toujours compilé ; actif seulement si VIRGL est proposé et que l'autotest passe. Code « présent universel » de #281 (deux copies plein écran par trame) retiré.
- Banc `tools/ci/run_gpu_composition.sh` (TCG local) : mire **254 934 pixels exacts, 0 faux** ; A/B DOOM **CONVAINCANT** (dessin CPU ÷15,7, pixels clients CPU −99,9 %, cadence conservée) ; repli 2D OK.
