# Dépendances et licences

Bouchaud Navigateur dérive de Ladybird, sous BSD 2-Clause au snapshot concerné.
D'autres dépendances peuvent inclure Skia, ICU, OpenSSL, HarfBuzz, FreeType et
d'autres bibliothèques.

Règles :
- conserver notices et copyrights ;
- documenter les dépendances ;
- épingler les versions importantes ;
- distinguer build et runtime ;
- ne pas présenter un moteur tiers comme from scratch.
